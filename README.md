# VR123 — лимунальное пространство

Вся игра — в одном файле: **[`index.html`](index.html)** (746 КБ: HTML + CSS + three.js + весь код внутри, внешних запросов нет, работает офлайн).

> **Почему не `.apk`.** Раньше файл назывался `VR123.apk`, и Android на нём писал
> «не удалось обработать этот пакет» — он ищет внутри ZIP c `AndroidManifest.xml`
> и `classes.dex`, а это HTML. Имя исправлено. Настоящий устанавливаемый `.apk`
> собирается отдельно — см. ниже.

## Как запустить прямо сейчас

- **Шлем (Quest / Pico):** скопируй `index.html` на устройство и открой в Oculus Browser — там есть WebXR и трекинг рук. Нажми «Войти в VR».
- **Телефон / ПК:** открой файл в Chrome. Если Android не даёт открыть файл из загрузок — переименуй его в `vr123.html`.
- **Без шлема:** режим с мышью/тачем — ПКМ осмотр, WASD, клавиши 1–7 переключают инструменты, N — нпс, C — камера.

## Как получить устанавливаемый .apk

### Вариант 1 — GitHub Actions (ничего устанавливать не нужно)
В репозитории есть [`.github/workflows/build-apk.yml`](.github/workflows/build-apk.yml):

1. Открой вкладку **Actions** → **Build APK** → **Run workflow**.
2. Дождись окончания (несколько минут).
3. Внизу страницы запуска скачай артефакт **`VR123-apk`** — внутри настоящий `app-debug.apk`.

⚠️ Этот воркфлоу здесь не запускался: ветка сессии зафиксирована на `arena/933b280c-vr123`,
а push в `main` мне недоступен, поэтому первый прогон будет уже у тебя. Если сборка упадёт
на версии SDK — поправь `compileSdk`/`buildToolsVersion` в `build/app/android`.

### Вариант 2 — локально (нужны Java 17+ и Android SDK)
```bash
npm i -g @capacitor/cli @capacitor/core
mkdir app && cp index.html app/ && cd app
npm init -y
npx cap init VR123 com.vr123.app --web-dir=.
npx cap add android && npx cap sync
cd android && ./gradlew assembleDebug
# -> android/app/build/outputs/apk/debug/app-debug.apk
```

В обоих случаях для WebXR внутри APK нужен WebView с поддержкой WebXR. Надёжнее всего
открывать `index.html` напрямую в Oculus Browser на шлеме — там WebXR и трекинг рук есть точно.

## Что внутри

- Белое лимунальное пространство: пол в клеточку 1×1 м, сетка-потолок, колонны, туман.
- Зеркальные аватары кистей: 21 сустав, 23 кости, повторяют движение руки и сгиб пальцев (WebXR hand-tracking), жест «пинч».
- Камера включается отдельной кнопкой, но остаётся скрытым слоем — её не видно.
- 7 инструментов: рука (брать/бросать), спавн кубиков с физикой, баллончик с краской (декали), сварка (дуга, искры, шов), пистолет, винтовка, меч.
- НПС: преследуют, бьют, кидаются кубиками, разваливаются на куски; одиночный спавн и «орда».
- Наручное меню на 10 пунктов (подними левую руку ладонью к себе), процедурный звук, HUD со счётом и HP.
