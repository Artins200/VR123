# VR123 — лимунальное пространство

Вся игра — в одном файле: **[`VR123.apk`](VR123.apk)** (728 КБ, HTML + CSS + three.js + весь код внутри, внешних запросов нет, работает офлайн).

## Как запустить

- **Шлем (Quest / Pico):** скопируй `VR123.apk` на устройство и открой в Oculus Browser — там есть WebXR и трекинг рук. Нажми «Войти в VR».
- **Телефон / ПК:** просто открой файл в Chrome — заработает режим без шлема (мышь/тач, WASD, клавиши 1–7).
- Файлу всё равно, что у него расширение `.apk` — это обычный самодостаточный HTML.

## Что внутри

- Белое лимунальное пространство: пол в клеточку 1×1 м, сетка-потолок, колонны, туман.
- Зеркальные аватары кистей: 21 сустав, 23 кости, повторяют движение руки и сгиб пальцев (WebXR hand-tracking), с жестом «пинч».
- Камера включается отдельной кнопкой, но остаётся скрытым слоем — её не видно.
- 7 инструментов: рука (брать/бросать), спавн кубиков с физикой, баллончик с краской (декали), сварка (дуга, искры, шов), пистолет, винтовка, меч.
- НПС: ходят, преследуют, бьют, кидаются кубиками, разваливаются на куски. Есть одиночный спавн и «орда».
- Наручное меню на 10 пунктов (подними левую руку ладонью к себе), процедурный звук, HUD со счётом и HP.

## Про «настоящий» бинарный .apk

Собрать бинарный APK в веб-песочнице нельзя: там нет ни `java`/`javac`, ни Android SDK
(`sdkmanager`, `aapt2`, `zipalign`, `apksigner`, `gradle` отсутствуют, `apt-get` без root,
хост загрузки SDK вне белого списка). Поэтому артефакт — самодостаточный файл, который
открывается на устройстве сразу.

Если нужен именно устанавливаемый `.apk`, на машине с Java 17 + Android SDK:

```bash
npm i -g @capacitor/cli @capacitor/core
mkdir app && cp VR123.apk app/index.html && cd app
npm init -y
npx cap init VR123 com.vr123.app --web-dir=.
npx cap add android && npx cap sync
cd android && ./gradlew assembleDebug
# -> android/app/build/outputs/apk/debug/app-debug.apk
```

Учти: для WebXR внутри такого APK нужен WebView с поддержкой WebXR. Надёжнее всего —
открывать файл напрямую в Oculus Browser на шлеме.
